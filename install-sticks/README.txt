Ready-to-copy install stick for the mod.

hmgapi-qipad-star-2.0.1  The HMG-API mod "Qi Pad Star Button" (qipad-star): the "Qi pad on/off"
                       choice in the star lists and the listener that switches the pad, in
                       one mod. Copy its HMGAPI folder to the top of a USB stick and install
                       it from the HMG-API app (Check USB updates). Its own README.txt has
                       the steps. Built 2026-11-13. It is 2.0.0 with the author and the
                       repository address added to mod.json; 2.0.0 was tested on the car
                       that evening (the pad switches only with the choice selected).

AFTER INSTALLING (required): in the car, Setup > Button > steering wheel star >
Qi pad on/off. The pad switches only with that setting.

The same package is attached to the release on GitHub.
Built with tools/make-hmgapi-mod/build-hmgapi-mod.sh. Design: docs/design.md.
